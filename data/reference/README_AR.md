# حزمة بيانات أنبت — النسخة 2

## الملفات
| الملف | الوصف |
|---|---|
| `ANBIT_reference.db` | القاعدة المرجعية النظيفة كاملة، ومعها سجل الري المولّد للأرشيف (14 ميجا) |
| `ANBIT_reference_app.db` | نفس القاعدة بدون السجل المولّد (0.2 ميجا)، وهي اللي يستخدمها التطبيق |
| `EDA_report.html` | تقرير التحليل الاستكشافي، عربي، فيه رسوم |
| `build_reference_db.py` | يبني القاعدة من `ENBT.db` (للقراءة فقط) |
| `fetch_weather.py` | يجلب طقس 2025 اليومي للمدن الـ14 من Open-Meteo |
| `eda_report.py` | يعيد إنتاج التقرير، ويقبل قواعد أو ملفات CSV إضافية |
| `CLAUDE_CODE_PROMPT.md` | برومبت دمج الحزمة في المشروع |

## وش تغيّر عن ENBT
- **عمق الجذور:** توحّد بالمتر، لأن الأعشاب كانت بالسنتيمتر.
- **`water_needs`:** بقي للأرشيف فقط، واستُبدل بمعاملات FAO-56:
  - Kc صيفي وشتوي، ومنها Kc شهري
  - عمق الجذور الفعّال
  - نسبة الاستنزاف p
- **24 نبات مسطحات خضراء** بمعاملات موثقة المصدر، منها نباتين جديدة: الجهنمية، وشجيرات تنسيق.
- **جداول جديدة:**
  - خصائص التربة: 11 نوع، من Hanson 2000
  - حدود الرطوبة لكل نبات وتربة: 264 صف
- **المدن:** أسماء عربية وإحداثيات، وجدولين للطقس اليومي والشهري.
- **حُذف:** `expected_water` لأنه نسخة من `water_needs`، و`recommendation` لأنه مشتق من الدرجة.
- **انصلح:** المفاتيح الأجنبية كانت تشير لجدول غير موجود (`Plants`).
- **سجل الري:** انتقل لجدول `irrigation_history_synthetic` وعليه وسم «مولّد»، بدون حذف أي صف.

## التشغيل
```bash
python3 build_reference_db.py ENBT.db ANBIT_reference_app.db --no-synthetic
python3 fetch_weather.py ANBIT_reference_app.db 2025
python3 eda_report.py --enbt ENBT.db --csv smart_irrigation_training_data.csv --ref ANBIT_reference_app.db --extra backend/anbit.db --out EDA_report.html
```

## حدود
- حدود الرطوبة ومعاملات النباتات **قيم عرض موثقة المصدر**، وتحتاج معايرة ميدانية قبل التشغيل الفعلي.
- معاملات الأعشاب الزينية والأغطية الأرضية **معاملات نبات من تصنيف WUCOLS**، مو Kc زراعي.
- طقس Open-Meteo **إعادة تحليل (ERA5)**، مو قياس محطة في موقع إكسبو.
