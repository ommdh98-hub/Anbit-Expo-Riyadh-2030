# أنبت | ANBIT

نموذج محلي متكامل لدعم قرارات الري عندما تكون قياسات التربة محدودة، لتحدي 2.1 في هاكاثون إكسبو الرياض 2030.

**نقيس أولًا، ثم نقرر بعناية.** يعرض أنبت فجوات القياس، يقترح نقطة فحص إضافية، ويتحقق من صلاحية المعلومات قبل إصدار قرار قابل للتفسير.

## الجمهوران والصلاحيات

- **الأفراد (`user`):** «ماذا أزرع في مدينتي وكيف أزرعه؟» — اختيار المدينة ثم النبات وفتح دليل عناية موثق. الدليل الأصلي ومعلومات التربة والري المبسطة متاحان من القائمة؛ أدوات المناطق المهنية تبقى لدى الفرق.
- **فرق المسطحات الخضراء (`survey`):** النباتات والمدن مع إدارة المناطق والقياسات والخريطة والتوأم والتوصيات والاعتماد والتنفيذ والتقارير.
- الحسابات وكلمات المرور ومعرّفات الأدوار الحالية محفوظة. [المصفوفة الفعلية وحدود البيانات](docs/AUDIENCES_AND_PERMISSIONS.md)، [المصادقة والصيانة](docs/AUTH_LOCAL_DEMO.md).

## التشغيل

المتطلبات: Node.js 20.9+ وPython 3.10+، Git. لا تحتاج مفاتيح API أو خدمات مدفوعة. يلزم الإنترنت لتثبيت المكتبات أول مرة فقط؛ الخط والشعار والبيانات محلية.

```bash
cd '/Users/ommdh/Desktop/Anbit | Expo Riyadh 2030'
bash scripts/setup.sh
bash scripts/start.sh
```

إذا كان `python3` أقدم من 3.10، عيّن `PYTHON_BIN` لمسار Python حديث قبل تشغيل setup. لا تستبدل Python النظام.

- التطبيق: http://127.0.0.1:3000
- API والتجربة التفاعلية: http://127.0.0.1:8000/docs
- OpenAPI: http://127.0.0.1:8000/openapi.json
- فحص الاتصال: http://127.0.0.1:8000/api/health

للعمل أثناء التطوير: شغّل `PYTHONPATH=backend .venv/bin/python -m uvicorn app.main:app --reload` في نافذة، و`npm --prefix frontend run dev` في أخرى. تجنّب تشغيل خادمي إنتاج وتطوير على المنفذ نفسه.

## ما يعمل

- Next.js + TypeScript بواجهة عربية RTL وخط IBM Plex Sans Arabic محلي.
- FastAPI وSQLModel وSQLite، مع تحقق من المدخلات ووثائق OpenAPI.
- خمس مناطق وسيناريوهات نقص القياس، الرطوبة المرتفعة، الاحتياج المحتمل، التضارب، والقراءات القديمة.
- خريطة SVG محلية تفاعلية وتغطية هندسية محسوبة من القراءات الحديثة المتحققة فقط.
- قراءة جديدة في نقطة موجودة أو مقترحة، مع الوحدة والوقت والمصدر والجودة والمسجّل.
- قرارات مستقلة عن الواجهة، مع أسباب وقواعد ومصادر وقراءات مستبعدة ومدخلات ناقصة.
- تقدير حسابي مشروط لاحتياج المياه واختبار افتراضات غير محفوظة.
- دورة مقترح ← معتمد/مؤجل ← منفّذ. الاعتماد لا يسجل مياه؛ التنفيذ يسجلها مرة واحدة.
- رفض التوصية المتقادمة، وطلب قراءات بعد آخر ري.
- سجل الفحص وتقارير اللترات والكميات المقاسة/المقدّرة، والمنطقة والفترة الزمنية.
- إعادة ضبط المحاكاة عملية صيانة منفصلة، محظورة على الجمهورين افتراضيًا ولا تظهر في الواجهة.

## ما هو محاكاة وما هو خارج النطاق

جميع بيانات الموقع والحدود الزراعية وعمق الجذور والكفاءة والتجانس **افتراضات تجريبية**. المخطط ليس خريطة إكسبو. لا اتصال بحساسات أو مضخات، ولا ML تشغيلي معتمد، ولا ادعاء توفير مثبت. دليل العناية مرجعي عام، لا تقويم زراعة سعودي أو وصفة ري ميدانية.

هذه نسخة محلية بتسجيل دخول وجلستين لدوري الأفراد وفرق المسطحات الخضراء، وصلاحيات تفرضها الواجهة والخادم. ليست نظام هوية جاهزًا للنشر العام؛ لا تعرّضها للإنترنت. مواقع التشغيل لها فصل بيانات في النموذج والـAPI، لكن واجهة إنشاء/معايرة موقع ميداني ليست ضمن هذه النسخة.

## الحفظ والنسخ الاحتياطي

قاعدة البيانات تُنشأ تلقائيًا في `backend/anbit.db`، ولا تُرفع إلى Git. لإعداد نسخة احتياطية متسقة:

```bash
.venv/bin/python scripts/backup.py
```

ينشأ ملف مؤرخ في `backups/`. لا تحذف قاعدة البيانات لاستعادة المحاكاة؛ أي إعادة ضبط عملية صيانة منفصلة تحتاج تفويضًا ولا تظهر للجمهورين. لإعادة العرض دون الإنترنت، ثبّت المكتبات وابنِ التطبيق مسبقًا، ثم شغّل `scripts/start.sh`.

## الاختبارات

```bash
bash scripts/test.sh
```

راجع `docs/VALIDATION.md` لنتائج الاختبار الفعلية وحدودها. المكتبات مثبتة في `frontend/package-lock.json` و`backend/requirements.lock.txt`.

## خريطة الملفات

- `frontend/app/`: الصفحات، التنسيق العام والخط.
- `frontend/components/`: تجربة التشغيل والخريطة والرسوم.
- `frontend/lib/`: عميل API وتعريفات البيانات.
- `backend/app/`: البيانات، القواعد، المسارات، والتحقق.
- `backend/tests/`: اختبارات الحسابات والرحلة والقيود.
- `docs/`: المصادر والافتراضات، العرض والتحقق.
- `TEAM_GUIDE.md`: دليل عملي لفهم الكود وتعديله.

## التوأم الرقمي التجريبي

من «خريطة الموقع»: حالة المناطق والقياسات والفجوات، مع تجربة كمية ماء افتراضية لا تغير السجلات. نموذج ثنائي الأبعاد قائم على المحاكاة والتحديث اليدوي، لا حساسات متصلة أو تنبؤ ML. [دليل التوأم ومعادلاته وحدوده](docs/DIGITAL_TWIN.md).


### التخطيط التنبؤي — محاكاة وبحث منفصلان

تتوفر لفرق المسطحات ملفات نبات/تربة محلية بالمتصفح، سيناريو24 ساعة وجدولة محاكاة، وتقرير إدارة للطباعة وCSV. لا تحكم بمضخة ولا تفعيل ML تشغيليًا. دراسة الآفاق1/3/6/12/24 ساعة مستقلة وتحفظ نتيجة OLS السابقة. راجع [التوثيق وحدود الاستخدام](docs/PREDICTIVE_IRRIGATION.md).
