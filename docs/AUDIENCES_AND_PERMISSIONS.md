# أنبت | ANBIT — الجمهوران والصلاحيات

المعرّفات الداخلية `user` و`survey` محفوظة للتوافق مع الحسابات والجلسات الحالية. أسماء العرض تُشتق من الدور دون تعديل سجلات الحسابات أو كلمات المرور. لا تعرّف الحسابات المشتركة شخصًا بعينه.

## نتيجة المراجعة والتصحيح

كانت `user` تملك إنشاء التوصيات والاعتماد وتأجيلها وتسجيل الري وإعادة ضبط المحاكاة، بينما `survey` تسجل القياسات والفحوصات فقط. كانت صفحة البداية متقاربة، ثم أصبحت الصفحة السابقة لـ`survey` خاصة بالقياس فقط. هذا التقسيم لا يعكس الجمهورين المطلوبين.

التقسيم الحالي: الأفراد لاكتشاف النباتات، وفرق المسطحات الخضراء لاكتشاف النباتات وإدارة الموقع كاملة. صلاحيات الخادم في `backend/app/auth.py`، والإجراءات الظاهرة والتنقل في `frontend/components/workspace.tsx` و`frontend/lib/role-home.ts`.

## المصفوفة الفعلية الحالية

| الميزة/العملية | الأفراد `user` | فرق المسطحات الخضراء `survey` |
|---|---|---|
| اختيار المدينة، استكشاف 17 نباتًا و238 تقييمًا في 14 مدينة | بداية التجربة | رابط مباشر في البداية والقائمة |
| معلومات النبات وأسباب التقييم، دليل النباتات الأصلي | نعم | نعم |
| قراءة المناطق والنقاط والقراءات والتغطية والفجوات والموقع المقترح | مسموح بالخادم؛ خارج رحلة الأفراد | نعم؛ ضمن إدارة الموقع |
| الخريطة والتوأم وتفاصيل القرارات والتحليلات | خارج واجهة الأفراد؛ الوصول الحسابي للقراءة فقط مسموح بالخادم | كامل |
| `POST /zones/{id}/estimate` و`/simulate` | نعم؛ دون حفظ | نعم؛ دون حفظ |
| قراءة سجل التوصيات وأحداث الري والتقارير | مسموح بالخادم | نعم؛ في القائمة |
| `POST /zones/{id}/measurements` | ممنوع 403 | مسموح مع التحقق |
| `POST /zones/{id}/inspections` | ممنوع 403 | مسموح |
| `POST /zones/{id}/recommendations` | ممنوع 403 | مسموح |
| `PATCH /recommendations/{id}` — اعتماد/تأجيل | ممنوع 403 | مسموح وفق صلاحية القرار |
| `POST /irrigation-events` | ممنوع 403 | مسموح بعد اعتماد صالح فقط |
| إعادة ضبط المحاكاة | ممنوع افتراضيًا | ممنوع افتراضيًا |
| تشغيل مضخة أو حساسات فعلية | غير موجود | غير موجود |

جميع مسارات الجدول تحت `/api`. كل جمهور يحتاج جلسة صالحة، ويظل التحقق من المنشأ والترويسة الوقائية ساريًا. السماح للدور لا يلغي تحقق البيانات، أو منع اعتماد قرار غير صالح أو متقادم، أو منع التنفيذ المكرر.

إعادة الضبط ليست صلاحية لأي جمهور: تتطلب جلسة مصادقة وتفويض صيانة منفصلًا موضحًا في [توثيق المصادقة](AUTH_LOCAL_DEMO.md). لا تظهر في الواجهة.

## البيانات والهوية

- مستكشف المدينة يستخدم المقتطف المرجعي الحالي دون تغيير قواعده أو أرقامه أو إدخالها في الري. الدرجة 0/50/100 ناتجة من مطابقة معياري الحرارة والرطوبة الجوية؛ ليست احتمال نجاح أو تنبؤًا معتمدًا. لا تُعرض قيم المناخ غير الموثقة كقياسات فعلية.
- المقتطف لا يوثّق العناية. أضيفت طبقة دليل مستقلة بمراجع زراعية عامة، تغطي النباتات الـ17 والأعشاب الأصلية الخمسة؛ لا تقويم سعودي أو جدول ري ثابت. راجع [دليل العناية ومصادره](GROWING_GUIDE.md). ملاحظات الدليل ومراجعه الأصلية محفوظة في القاعدة وتُعرض بصياغة محايدة.
- الرطوبة الجوية ليست رطوبة تربة. بيانات الموقع محاكاة، والحساب المائي مشروط بقياسات صالحة وتغطية هندسية ومدخلات معتمدة في المحرك. التغطية ليست ثقة إحصائية. لا ادعاء توفير ماء محقق.
- الهوية الوحيدة للمنتج: **أنبت | ANBIT**. تُعرض نسبة المرجع الداخلي بصياغة محايدة صادقة دون العلامة السابقة؛ تبقى سجلات المصدر التاريخية ومعرّفاتها في قاعدة البيانات دون تعديل. **ENBT.db** اسم ملف مصدر المستكشف الاختياري وليس هوية المنتج.
- لم تتغير معادلات الري أو المحاكاة أو بيانات النباتات أو قاعدة التشغيل. اختبارات الصلاحيات تستخدم قواعد مؤقتة معزولة، ولا تعيد إنشاء حسابات التشغيل.
